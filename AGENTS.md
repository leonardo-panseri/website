## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

A pre-commit hook (`.githooks/pre-commit`) runs Biome on staged files and rejects the commit on any lint or format error. Before committing, auto-fix the files you modified with `pnpm check:fix <files>`, then stage them.

Write commit messages in [Conventional Commits](https://www.conventionalcommits.org/) style (e.g. `feat: add tag pages`, `fix: correct RSS date`).
